# Technical Communication Skill

Двуязычный skill для Codex, который помогает писать ясные и предметные тексты в технической работе.

Он подходит для клиентской и деловой переписки, предложений, статусов по проекту, технических объяснений, решений и документации на русском или английском языке. Тон остаётся прямым, спокойным, конкретным и человеческим. Skill не привязан к бирже, компании или конкретному автору.

English version: [README.md](README.md).

## Что умеет

- предложения клиентам, партнёрам и на фрилансе;
- деловая переписка в технических проектах и follow-up сообщения;
- статусы по проекту, инцидентам и поставке;
- технические объяснения с понятными границами и решениями;
- подготовка и редактирование технической документации;
- переработка шаблонного, раздутого или машинного текста.

Skill не заменяет экспертизу в предметной области, юридическую или security-проверку и продуктовые решения. Он не придумывает факты, опыт, оценки, обязательства и доступы.

## Установка

```bash
git clone https://github.com/borkli/technical-communication-skill.git \
  ~/.codex/skills/technical-communication
```

После установки перезапустите Codex, чтобы skill появился в списке доступных.

## Использование

Skill можно вызвать явно либо дать Codex выбрать его для подходящей задачи.

```text
Используй $technical-communication и напиши короткий статус для клиента:
миграция API завершена, smoke-тест на staging прошёл, для выката в production нужно подтверждение.
```

По умолчанию ответ создаётся на языке запроса. Перевод или другой язык выполняются только по явной просьбе.

## Структура

```text
technical-communication/
├── SKILL.md
├── agents/openai.yaml
└── references/
    ├── formats.en.md
    ├── formats.ru.md
    ├── rules.en.md
    └── rules.ru.md
```

В `SKILL.md` находится общий рабочий процесс, а правила и форматы для каждого языка вынесены в отдельные файлы. Это сохраняет русский и английский равноправными и не смешивает разные языковые нормы в одном наборе примеров.
